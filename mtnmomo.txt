Partie

Party identifie un titulaire de compte sur la plate-forme de portefeuille. Party se compose de deux paramètres, le type et le partyId. Chaque type a sa propre validation du partiId
MSISDN - Numéro de téléphone mobile validé selon ITU-T E.164. Validé avec IsMSIDN
EMAIL - Validé pour être un format de courriel valide. Validé avec IsEmail
PARTY_CODE - UUID du parti. Validé avec IsUuid
{
    "type": "object",
    "properties": {
        "partyIdType": {
            "enum": [
                "MSISDN",
                "EMAIL",
                "PARTY_CODE"
            ],
            "type": "string"
        },
        "partyId": {
            "type": "string"
        }
    },
    "description": "Party identifies a account holder in the wallet platform. Party consists of two parameters, type and partyId. Each type have its own validation of the partyId<br> MSISDN - Mobile Number validated according to ITU-T E.164. Validated with IsMSISDN<br> EMAIL - Validated to be a valid e-mail format. Validated with IsEmail<br> PARTY_CODE - UUID of the party. Validated with IsUuid"
}
